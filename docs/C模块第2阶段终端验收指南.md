## 正常请求、拒绝、参数、截断与超时恢复

新内部入口为 SQLExecutor.execute_sql(request, access)，输出严格沿用 v0.3 SQL 对象。不是旧 chinook_c.query；没有新增 B HTTP 接口。

```powershell
@'
import json
from backend.sql_module import Registry, AccessContext
from backend.sql_module.execution import SQLExecutor
r = Registry.load()
e = SQLExecutor(r)
a = AccessContext.local(r)
cases = [
    ("count", "SELECT COUNT(*) AS customer_count FROM Customer", {}),
    ("write", "DELETE FROM Customer", {}),
    ("multiple", "SELECT 1; SELECT 2", {}),
    ("unsafe", "SELECT load_extension(:x)", {"params":{"x":"example"}}),
    ("limit", "SELECT GenreId FROM Genre ORDER BY GenreId", {"max_rows":3}),
    ("empty", "SELECT Name FROM Genre WHERE Name=:name", {"params":{"name":"Rock' OR 1=1 --"}}),
    ("timeout", "SELECT SUM(a.TrackId+b.TrackId+c.TrackId) AS n FROM Track a CROSS JOIN Track b CROSS JOIN Track c", {"timeout_ms":1}),
    ("recover", "SELECT 1 AS n", {})
]
for label, sql, options in cases:
    request = dict(query_id=label, profile_id="chinook", sql=sql, **options)
    print(label, json.dumps(e.execute_sql(request, a), ensure_ascii=False))
'@ | .\.venv\Scripts\python.exe -
```

预期：count success、customer_count=59、source.tables=[main.Customer]；write/multiple/unsafe rejected、SQL_READ_ONLY_VIOLATION；limit 3 行、truncated=true；empty success、零行；timeout failed、SQL_EXECUTION_FAILED、reason=TIMEOUT；recover success、n=1。返回所有 v0.3 字段，不返回 sql 额外字段或堆栈。execution_ms 包含配置/结构/校验耗时。

## PostgreSQL 与限制

AdventureWorks 尚未部署，当前 PG 专项只完成 AST 与参数编译模拟。真实环境准备后按阶段一指南配置本地 profile/环境变量并重跑；还需最小权限账号、真实跨 Schema/复合键和事务的实际验收，不自行建表或改库。

保守允许清单支持 SELECT、普通 CTE、聚合、连接、子查询、集合查询、受控 CAST；拒绝递归 CTE、窗口函数及未允许表达式，部分合法只读语句会被拒绝。业务口径与复杂查询效果留后续阶段。

Decimal 序列化为字符串、日期时间 ISO、NULL 保留；字节/非有限数值失败。max_rows 限制返回，不保证计算量小。timeout_ms 从取得执行连接后计时，不是全请求硬截止；连接/元数据有独立预算。每次独立连接销毁，恢复测试不意味着同连接池复用。正式契约与旧模块未修改。
