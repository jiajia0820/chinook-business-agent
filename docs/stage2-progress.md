## 约束与版本管理

- 执行已批准的 `docs/superpowers/specs/2026-10-10-stage2-design.md`。

## 后续版本备注格式

每个版本依次写明：版本号与目的 → 涉及文件/行为 → 实际验证与逐组成绩 → 证据路径 → 剩余问题/退化/API 暂缓 → 验收状态与回溯标记。
