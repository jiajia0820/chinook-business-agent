## 边界

SQLGlot 结构策略不是数据库权限系统；使用只读连接/事务、SQLite authorizer、受控 search_path、SQL/元数据/连接预算和输出上限。PG 最小权限账号及真实设置仍待验证。支持清单有意保守，不承诺任意只读 SQL 或业务语义正确。

timeout_ms 约束执行阶段，不是全请求硬截止；返回截断不等于控制计算量。无连接池，每次连接清理销毁。正式 v0.3 不修改，旧接口保留。
