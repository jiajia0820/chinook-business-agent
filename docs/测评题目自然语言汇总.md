# 测评题目自然语言汇总

> 本文件依据 `eval/agent/eval_manifest.json` 与 `eval/human/README.md` 整理。仅保留发送给 Agent 的自然语言问题，并按正式测评能力顺序排列。

正式单轮题共 114 道；多轮会话共 5 组、15 个轮次。`clarification_v3`、`c_v2` 等开发诊断集不计入本汇总。

1. 2025年第三季度音频销售额、销量、订单数和购买客户数分别是多少？

10. 2025年第三季度音频销售额最高的五个账单国家是什么？
