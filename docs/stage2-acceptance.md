## 回溯办法

先保存尚未提交的工作，再使用 `git switch --detach stage2-S2-004` 查看指定旧版本；要基于旧版本继续开发，用 `git switch -c <新本地分支> <版本标签>`。
需要撤销已提交的改动时优先 `git revert <提交>`，保留迭代历史。运行日志与 `.env` 不随代码版本回滚，独立保存在本地。
远程推送须等用户全部验收并明确授权；达到机器门槛不等同于用户验收。
