# C 模块真实模型接入验证

日期：2026-10-03。使用现有 HTTPJSONModel、NLQueryService 和只读执行器，未使用 DemoJSONModel。没有修改产品代码或正式接口；密钥仅在验证进程内使用，没有保存到本文件或配置文件。

## 服务与配置

- 完整请求地址：`https://api.hcnsec.cn/v1/chat/completions`。
- 请求模型 ID：`DeepSeek-V4-Pro`。
- 独立小请求 HTTP 200；响应的 model 字段为 `self-dploy/DeepSeek-V4-Flash-Vision-Exp`，与请求名称不同。该网关实际路由不能仅凭请求名称确认。
- 使用现有变量 `C_SQL_MODEL_ENDPOINT`、`C_SQL_MODEL_NAME`、`C_SQL_MODEL_API_KEY`，并非自动读取用户提供的 `LLM_*` 名称或 `.env`。

## 实测结果

最初沙箱网络禁止套接字连接；允许外网后，第一条完整请求超过现有 20 秒模型预算，返回 MODEL_TIMEOUT。随后三个独立问题均实际返回 answered：

| 问题 | 实际结果 | 全流程耗时 | 核对 |
|---|---|---|---|
| 咱们这份数据一共记录了多少位客户？结果列请叫 customer_count。 | customer_count=59 | 19.02 秒 | 与独立 SQLite 查询完全一致 |
| 按客户所在国家统计客户数量，返回 Country 和 customer_count，数量从高到低，数量相同时按国家升序，取前五个国家。 | USA 13、Canada 8、Brazil 5、France 5、Germany 4 | 18.53 秒 | 值和顺序一致，返回 country 而非 Country |
| 统计每个音乐类型包含多少首曲目，返回 Name 和 track_count，按曲目数降序、类型名称升序排列，只取前三种。 | Rock 1297、Latin 579、Metal 374 | 9.25 秒 | 值和顺序一致，返回 name 而非 Name |

原始字典严格比较中，后两题因键名大小写差异判定不一致，不能描述为严格字段一致通过。模型生成了正确的分组和基础关联查询；现有执行/重写流程输出列名归一化需要后续核查。本轮不修改执行逻辑。

基础关联 SQL 使用 main.Genre 与 main.Track，模型生成 LEFT JOIN，基准查询使用 JOIN；这道前 3 名问题的返回结果一致，不证明不同数据条件下两种连接普遍等价。

## VS Code 使用方法

在 VS Code 打开 chinook-business-agent，使用该项目 .venv/Scripts/python.exe。以下为同一个 PowerShell 终端内的配置；关闭终端后需要重新配置。密钥通过隐藏输入输入，不写入命令历史。

```powershell
$env:C_SQL_MODEL_ENDPOINT = 'https://api.hcnsec.cn/v1/chat/completions'
$env:C_SQL_MODEL_NAME = 'DeepSeek-V4-Pro'
$modelSecret = Read-Host '输入模型 API Key' -AsSecureString
$modelCredential = [System.Management.Automation.PSCredential]::new('model', $modelSecret)
$env:C_SQL_MODEL_API_KEY = $modelCredential.GetNetworkCredential().Password
Remove-Variable modelSecret, modelCredential
.\.venv\Scripts\python.exe -m backend.sql_module ask chinook '一共有多少位客户？'
```

真实模型测试不要添加 `--demo-model`。输出为结构化 JSON，含 sql_results、query_artifacts 和错误/限制信息，不是页面聊天窗口。原始完整端点已经包含 /chat/completions，不能再次拼接同一路径。

## 验证边界

真实模型到真实 Chinook 的基础链路已有成功实例，包含非预设问法与一条基础多表关联。接口响应时间存在接近或超过 20 秒预算的情况；不能称为稳定性验收完成。三个成功问题不能视为独立评测准确率；A 口径、复杂查询、精准 Schema Linking、自动修复、AdventureWorks 和 B 页面联调仍未完成正式验证。密钥未持久化，因此本次运行环境不会自动传递到用户的新 VS Code 终端。
