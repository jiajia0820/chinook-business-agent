## B 先看什么、如何调用

先读 [当前状态与 B 调用指南](C模块当前状态与B调用指南-2026-10-04.md)，其中包含可直接参考的 Python 调用示例、权限、字段、错误和展示要求。

- 新自然语言入口：`backend.sql_module.service.NLQueryService.answer_sql(request, access)`，同步 Python 调用。
- 显式 SQL 入口：`backend.sql_module.execution.SQLExecutor.execute_sql`。
- 配置：[Chinook profile](../profiles/chinook/profile.json)、[空环境变量模板](../.env.example)、[依赖](../requirements-c.txt)。模块不会自动加载 `.env`，需将配置放入后端进程环境。
- 示例：[自然语言请求](../examples/c-nl-query.json)、[SQL 请求](../examples/c-sql-query.json)。
- 当前没有新增可直接调用的 NL2SQL HTTP 服务；旧 `backend/chinook_c.py` 是规则基线，新模块返回内部结果草案，需要 B 组织为团队最终接口响应。
- 页面展示 SQL、结果、来源、口径及 limitations；answered 只表示执行完成，仍需审查业务条件是否满足。权限上下文应由后端根据认证身份构造。

## 复现入口（项目根目录）

```powershell
python -m pip install -r requirements-c.txt
python -m backend.sql_module check chinook
python -m backend.sql_module query --request-file examples/c-sql-query.json
python -m backend.sql_module ask chinook --request-file examples/c-nl-query.json --demo-model
python -m unittest discover -s eval -p 'test*.py' -v
```

`--demo-model` 为固定问法离线演示，用实际 Chinook 查询验证调用链，不能作为模型正确率依据。真实模型需要后端配置 `C_SQL_MODEL_ENDPOINT`、`C_SQL_MODEL_NAME`、`C_SQL_MODEL_API_KEY` 并去掉该参数，详细步骤见 B 调用指南。
